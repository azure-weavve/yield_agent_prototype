# P2-5 교락 문장: "무엇을 보면 갈리는가" (confound-next-look)

## 목표와 요구사항

교락 근거 줄이 "현재 증거로는 구분되지 않는다" 로 **끝나지 않게** 한다. 바로 아래
`rolled_up_as` 문장처럼 **두 이름을 대고 무엇이 없어서 못 가르는지, 무엇을 더하면
갈리는지**를 말한다. 출처: `docs/next_step_claude.md` P2-5.

## 범위

- 안: `graph/evidence.py::format_group_line` 의 `confounded_with` 문장 1곳, 그 테스트.
- 밖: 접기 규칙(`ranked_groups`), 판정 이름·하한·반려 사유, LLM 프롬프트(`llm/client.py`
  는 이미 "무엇을 더 봐야 갈리는지 적어라" 를 지시한다), 구조화 필드 추가(P2-6 몫),
  동점(`tied`) 문장(같은 "현재 증거로는" 구절을 쓰지만 다른 사실이다).

## 기준

## 동결과의 관계 (사용자 결정 2026-09-23)

`format_group_line` 은 리포트 `[근거]` 줄(`nodes.py` 리포트 조립)뿐 아니라 **confirmed

따라서 이 변경은 판정문 문구를 바꾼다. 사용자가 **동결의 1회 예외로 허용**했다.
허용 범위: 교락 문장 꼬리 추가만. 판정 이름·하한·반려 사유·다른 문장은 그대로.

## 코드 사실 (검증함)

- 교락 = `ranked_groups` 가 **타깃 wafer 집합과 대조군 wafer 집합이 모두 같은** 후보를
  한 버킷으로 접은 것(`evidence.py` `key = (frozenset(target_wafers), frozenset(control_wafers))`).
  `target_wafers`/`control_wafers` 는 도구가 비트로 낸 **전체** 목록이다
  (`tools/commonality.py` `_names(e.get("c_bits"...))`), 잘린 목록이 아니다.
- 따라서 접혔다는 사실 자체가 "타깃·대조군 안에 한쪽만 통과한 wafer 가 **양방향 모두**
  없다" 의 증명이다. 포함관계(`rolled_up_as`)는 한 방향만 가능하지만 교락은 양방향이다.
- 대조군 = 타깃과 같은 root_lot 의 비타깃 wafer 전원(`tools/grouping.py::select_control`).
  즉 현재 root_lot 안에서는 더 찾을 wafer 가 없고, 가르는 wafer 는 **다른 lot** 에 있다.
- `confounded_with` 의 각 항목은 대표(`group["key"]`)와 같은 집합이므로 상대는 항상 대표다
  (포함관계와 달리 `of` 필드가 필요 없다).

## 설계

문장 (대표 `L`, 접힌 쪽 `O`):

```
같은 wafer 를 O(level) 로도 설명할 수 있다 (교락){detail} - 현재 증거로는 구분되지 않는다.
타깃·대조군에 'L 통과 · O 미통과' 도 그 반대도 없어 둘을 가를 대조가 없다 -
둘 중 한쪽만 통과한 wafer 가 있는 다른 lot 을 대조에 더해야 갈린다
```

(실제로는 한 줄. 줄바꿈은 가독용.)

- "현재 증거로는 구분되지 않는다" 는 **남긴다** - LLM 프롬프트가 이 구절을 쓰라고
  지시하고 기존 단언(`test_multi_axis_dummy`)이 잡고 있다. 요구는 "그걸로 끝나지 않게" 다.
- "다른 lot" 조치는 지금 에이전트가 할 수 없다(`group_ids`/`control_ids` 가
  InjectedToolArg, P3-8). 문장은 엔지니어에게 하는 말이므로 그대로 적는다.
- 가정(미검증): 계측(metro) 후보가 교락에 섞이면 분모가 잰 wafer 뿐이라 "대조군에 없다"
  는 잰 wafer 안에서만 참이다. 포함관계 문장도 같은 한계를 가지므로 이번에 따로 다루지 않는다.

## 설계 수정 (Opus 리뷰 M1 반영, 2026-09-23)

위 설계의 "다른 lot 을 더해야 갈린다" 와 "포함관계도 같은 한계" 가정은 **틀렸다.**
접기 키의 두 집합은 도구가 통과로 **관측한** wafer 뿐이다. 그래서 다음 wafer 는 어느
집합에도 들어가지 않아 접기를 막지 못한다: 안 잰 wafer(metro 분모는 잰 wafer 뿐),
축 이력이 결측인 wafer, 대조군이 없는 root_lot 의 타깃(`paired` 필터로 빠짐).
이 wafer 들이 같은 root_lot 안에서 둘을 가를 수 있다. 포함관계는 같은 legend 의
설비 ⊃ 챔버라 결측이 있어도 참이다. 따라서 이 한계는 교락에만 있다.

조건 분기(분모가 다를 때만 한정어 추가)는 쓰지 않는다. 분모가 같아도 결측이 없다는
보장이 없기 때문이다. 대신 **항상 참인 문장**으로 바꾼다:

```
... - 현재 증거로는 구분되지 않는다. 비교에 들어간 wafer 에는 'L 통과 · O 미통과' 도
그 반대도 없어 둘을 가를 대조가 없다 - 비교에서 빠진 wafer(안 잰 wafer·이력 결측 등)를
채우거나 다른 root_lot 을 대조에 더하면 갈릴 수 있다
```

- "lot" 을 "root_lot" 으로 바꾼다. 대조군은 이미 같은 root_lot 의 분할 lot 을 포함한다(m5).
- 필요조건("더해야 갈린다")을 가능성("더하면 갈릴 수 있다")으로 낮춘다.
- 포함관계 주석의 "교락은 다른 축을 더 보는 것" 은 낡았으므로 고친다(m1).
  교락 쌍은 wafer 집합이 같아 다른 축을 더 봐도 갈리지 않는다.
